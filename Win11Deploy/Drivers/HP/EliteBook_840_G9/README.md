# Drivers: HP EliteBook 840 G9 (example)

Extract SoftPaq driver content for this product into this folder.

Required: one or more `.inf` files (subdirectories are fine).  
Match `models.json` `productPatterns` to the machine’s product number (e.g. `6F5Y2UT#ABA`).

Suggested components: chipset, storage, NIC/Wi-Fi, GPU, audio, dock.
